# ProyectoFinalSueño - React Native (Expo)

Aplicación móvil creada para el **seguimiento del sueño**, desarrollada con **React Native** y **JavaScript**.

## Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
cd ProyectoFinal
```

## Instalar dependencias

```bash
npm install
```

> Esto instala todo lo definido en `package.json`.

## Ejecutar el proyecto

```bash
npx expo start
```

Luego elige una opción en la terminal:

| Tecla | Acción |
|-------|--------|
| `a`   | Abrir en emulador Android |
| `i`   | Abrir en simulador iOS |
| `w`   | Abrir en navegador (web) |
| `r`   | Recargar la app |

También puedes escanear el código QR con la app **Expo Go** desde tu celular.

---


## Requisitos previos

- [Node.js](https://nodejs.org/) (versión recomendada: LTS)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [Git](https://git-scm.com/)
